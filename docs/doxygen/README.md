# Doxygen support files

- `md_filter.py`: input filter for Markdown pages. It draws ```mermaid blocks with mermaid.js
  and points links to repository files at GitHub.
- `doxygen-awesome.css`, `doxygen-awesome-sidebar-only.css`: the
  [doxygen-awesome-css](https://github.com/jothepro/doxygen-awesome-css) theme, v2.4.2, MIT
  (`LICENSE.doxygen-awesome-css`), vendored so the build needs no network access.
